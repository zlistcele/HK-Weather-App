# HKWeatherApp

A weather application built with SwiftUI for iOS/macOS platforms.

## Overview

HKWeatherApp is a native Swift application that provides weather information using SwiftUI for the user interface. The app features a responsive design with a minimum window size of 400x300 points.

## Requirements

- macOS 12.0+ / iOS 15.0+ (or later)
- Xcode 13.0+ (or later)
- Swift 5.5+

## Project Structure

```
HKWeatherApp/
├── HKWeatherAppApp.swift    # Main app entry point
└── ContentView.swift        # Main content view (required)
```

## Getting Started

1. Clone the repository
2. Open the project in Xcode
3. Build and run the application

## Usage

Launch the application to view the weather interface. The app window can be resized but will maintain a minimum size of 400x300 points for optimal viewing.

## Technologies

- **SwiftUI** - Declarative UI framework
- **Swift** - Programming language
